# Inner Auth - 初始设计文档

## 项目概述

Inner Auth 是一个统一的内部服务鉴权网关，提供认证页面和反向代理功能。

## 功能需求

1. **反向代理**：监听指定端口，认证通过后转发请求到上游服务
2. **认证页面**：用户名 + 密码 + 可选 TOTP 验证
3. **会话管理**：JWT Token 存储在 HttpOnly Cookie 中
4. **安全防护**：IP 级别和全局级别的登录速率限制

## 配置文件设计

```json
{
  "listen_port": 6904,
  "upstream": "http://127.0.0.1:4096",
  "title": "My Service Login",
  "jwt_secret": "your-random-secret-key",
  "session_ttl_hours": 168,
  "rate_limit": {
    "max_attempts_per_ip": 5,
    "ip_window_seconds": 60,
    "ip_lockout_seconds": 300,
    "global_max_attempts": 200,
    "global_window_seconds": 3600
  },
  "auth": {
    "user": "your_username",
    "password": "your_password",
    "totp_token": ""
  }
}
```

### 配置项说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `listen_port` | int | 监听端口 |
| `upstream` | string | 上游服务地址 |
| `title` | string | 登录页面标题，默认 "Login" |
| `jwt_secret` | string | JWT 签名密钥 |
| `session_ttl_hours` | int | 会话时长（小时），默认 168（7天） |
| `rate_limit` | object | 速率限制配置 |
| `auth` | object | 认证信息 |

#### rate_limit 配置

| 字段 | 类型 | 说明 |
|------|------|------|
| `max_attempts_per_ip` | int | 单 IP 最大尝试次数，默认 5 |
| `ip_window_seconds` | int | IP 限制窗口期（秒），默认 60 |
| `ip_lockout_seconds` | int | IP 锁定时长（秒），默认 300 |
| `global_max_attempts` | int | 全局最大尝试次数，默认 200 |
| `global_window_seconds` | int | 全局限制窗口期（秒），默认 3600 |

#### auth 配置

| 字段 | 类型 | 说明 |
|------|------|------|
| `user` | string | 用户名 |
| `password` | string | 密码 |
| `totp_token` | string | TOTP 密钥（base32 编码），为空时跳过 TOTP 验证 |

## 认证流程

```
请求进入 :6904
    │
    ├─ 检查 Cookie JWT
    │   └─ 有效 → 转发到 upstream
    │
    ├─ 无/无效 Cookie
    │   │
    │   ├─ GET /login → 显示登录页面
    │   │
    │   └─ POST /login
    │       │
    │       ├─ 1. 检查全局限制
    │       │   └─ 失败 >= 200 (本小时) → 返回 429
    │       │
    │       ├─ 2. 检查 IP 限制
    │       │   └─ 失败 >= 5 (本分钟) → 返回 429
    │       │
    │       ├─ 3. 验证凭据
    │       │   ├─ 失败 → 计数+1，返回错误
    │       │   └─ 成功 → 清除 IP 计数，生成 JWT
    │       │
    │       └─ 4. 重定向到原始请求路径
    │
    └─ 其他路径（无 Cookie）→ 重定向到 /login
```

## 技术选型

### 后端

- **语言**：Go
- **HTTP 框架**：Gin
- **JWT 库**：github.com/golang-jwt/jwt/v5
- **TOTP 库**：github.com/pquerna/otp

### 前端

- **技术**：纯 HTML + CSS（Go 模板渲染）
- **风格**：深色主题，黑白配色，简约设计
- **响应式**：支持移动端和桌面端
- **密码管理器友好**：标准表单 + autocomplete 属性

## 安全设计

1. **Cookie 安全**：HttpOnly + SameSite=Strict
2. **JWT 过期**：7 天自动过期
3. **IP 限制**：5 次/分钟，锁定 5 分钟
4. **全局限制**：200 次/小时，锁定到该小时结束
5. **密码存储**：明文（可扩展为 bcrypt）
